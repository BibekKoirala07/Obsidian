## ✅ What You Learn by Studying Supabase & Firebase

### 1️⃣ Authentication Systems (Real-World Level)

Both platforms implement:

- Email/password auth
    
- OAuth (Google, GitHub, etc.)
    
- JWT-based sessions
    
- Refresh tokens
    
- Role-based access
    

When you study them, you’re learning:

> “How do big systems manage identity at scale?”

This directly connects to what you’ve done with JWT + Passport in NestJS.

---

### 2️⃣ Database + Security (Very Important)

#### Supabase (SQL-style)

Built on **PostgreSQL**

It teaches you:

- Row Level Security (RLS)
    
- Policies = DB-level authorization
    
- Views + Functions
    
- Real-time on SQL
    

This is advanced backend design.

#### Firebase (NoSQL-style)

Built on document storage

It teaches:

- Collection design
    
- Security rules
    
- Indexing strategy
    
- Denormalization
    

So you learn **SQL vs NoSQL design in practice.**

---

### 3️⃣ API Layer (How APIs Are Generated)

Supabase:

- Auto-generates REST & GraphQL from DB
    

Firebase:

- SDK-based APIs
    
- Cloud Functions
    

You learn:

> How APIs can be auto-generated vs hand-written

Which helps in system design interviews.

---

### 4️⃣ File Storage & CDN

Both offer:

- Object storage
    
- CDN delivery
    
- Access control
    

This teaches:

- How uploads work
    
- How URLs are signed
    
- How private files are protected
    

Very important for production systems.

---

### 5️⃣ Serverless & Background Jobs

Firebase:

- Cloud Functions
    

Supabase:

- Edge Functions
    

You learn:

- Event-driven systems
    
- Async processing
    
- Webhooks
    
- Queues (indirectly)
    

This is real backend architecture.

---

## 🧠 How YOU Should Study Them (Best Way)

Don’t just “use” them. Reverse-engineer them.

### Step 1: Build Something Small

Example:

> “Mini Instagram clone”

With:

- Auth
    
- Posts
    
- Likes
    
- Images
    
- Comments
    

Build once in Supabase  
Build once in Firebase

Then ask:

> “How did they solve this?”

---

### Step 2: Map to Your Own Stack

While using them, always think:

|Feature|Supabase/Firebase|Your NestJS|
|---|---|---|
|Auth|Managed|Passport/JWT|
|DB|Managed|Mongo/PG|
|Storage|Built-in|S3/MinIO|
|Realtime|Built-in|Socket.io|
|Functions|Edge|Workers/Queues|

This turns platforms into **learning tools**, not crutches.

---

### Step 3: Rebuild One Feature Yourself

Example:

After learning Supabase Auth →  
Build your own:

- Access token
    
- Refresh token
    
- Revocation
    
- RLS-style guards
    

You already started doing this. That’s why this fits you.
