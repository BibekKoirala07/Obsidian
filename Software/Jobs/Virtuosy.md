## About the job

  

We are looking for a Backend Developer (Devops) with strong Devops knowledge to join our team. The main focus of this role is to build and maintain infrastructure, deployment pipelines, and monitoring systems. Backend knowledge will be useful for working closely with developers and understanding how applications run in production.

  

**Key Responsibilities**

- Design, implement, and maintain CI/CD pipelines for efficient software delivery.
- Manage and optimize cloud infrastructure (AWS, Azure, or GCP) using Infrastructure as Code (Terraform, Ansible, etc.).
- Automate deployment, monitoring, and scaling of applications.
- Collaborate with backend developers to ensure seamless integration between infrastructure and application code.
- Implement containerization and orchestration (Docker, Kubernetes).
- Monitor system health, troubleshoot issues, and ensure high availability.
- Apply security best practices across infrastructure and backend systems.

**Requirements**

- 4+ years of professional experience in DevOps engineering.
- Excellent knowledge of DevOps practices: CI/CD, cloud platforms, containerization, monitoring, and automation.
- Strong backend development knowledge (JavaScript/Node.js preferred; other backend languages a plus).
- Experience with version control (Git) and agile methodologies.
- Familiarity with databases (SQL/NoSQL) and API integration.
- Strong problem-solving skills and ability to collaborate across teams.

**Nice-to-Have**

- Experience with microservices and serverless architectures.
- Exposure to observability tools (Prometheus, Grafana, ELK stack).
- Contributions to DevOps or backend open-source projects.
