| Term              | Meaning                                                   |
| ----------------- | --------------------------------------------------------- |
| App               | Your software that integrates with Shopify                |
| App installation  | Merchant connects your app to their store                 |
| Authorization     | Merchant grants your app permission                       |
| Access token      | Credential your app uses to call Shopify APIs             |
| Scopes            | Permissions your app requests                             |
| Webhook           | Shopify sends your server an event when something happens |
| API               | Interface your app uses to communicate with Shopify       |
| Fulfillment       | Process of preparing and shipping an order                |
| Refund            | Returning money to a customer                             |
| Checkout          | Process where a customer completes a purchase             |
| Cart              | Collection of products a customer intends to purchase     |
| SKU               | Merchant-defined identifier for a product variant         |
| Metafield         | Custom data attached to Shopify resources                 |
| Metaobject        | A reusable custom data structure                          |
| Storefront        | The customer-facing shopping website                      |
| Admin             | The merchant-facing management dashboard                  |
| POS               | Point of Sale; in-person selling system                   |
| Headless commerce | Using Shopify's commerce backend with your own frontend   |
