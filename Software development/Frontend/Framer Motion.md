Framer Motion offers things like `<motion.div> motion.p motion.button` etc. They work exactly like their static counterparts but unlike normal jsx, they offer special animation props such as animate, transition, hover & tap gestures and much more.

###### animate
You have to know only `animate` tag is responsible for animation. and not other. Thus whatever style that we wish to animate must be defined in that tag. 

###### transition
It allows to control over properties such as `duration easing delay staggerchildren loop repeat` using `transition` tag.
