Java has 51 reserved words that are used for keywords in our applications. Ironic is that underscore by itself is a keyword. IntelliJ highlights keywords(reserved words) in blue.

Java also has 16 contextual keywords(means they are only keywords in special situations). Some of them are `exports opens requires uses`.

Java's Code Unit.
Learning code is similar to writing a document. It consist of special hierarchical units which together form a whole. They are Expression(it computes to a single value), Statement(stand alone units of work), Code Blocks(A code block is a set of zero, one or more statements, usually grouped together in some way to achieve a single goal).

Here `100 * 1.609344` is a expression. The entire line written below is valid statement. However actual statement is `kilometers = (100 * 1.609344)`. The data types and semi colon.
```java
	double kilometers = (100 * 1.609344);
```
Normally expression component can include variables, values and operators. here `kilometers` is variable, and `100 1.609344` are values and `*` are operators. By combining semicolon and data type, we've now created a valid Java statement.

Whitespace and Code Organization
Java statement can be my assignments expression or something like `myVarialbe++ or myVariable--`. The semicolon make this things a statement. without semicolon it is just an expression. The semicolon is needed to complete a java line to make it a statement, in most cases, but there are exceptions to this. 

White space is any extra spacing, horizontally or vertically, placed around Java source code. However more than one extra space is ignored. Internally it deletes the white space before it process the code.
